# 살 것 - 무료 개인용 장보기 PWA

기능
- 품목 추가/수정/삭제
- 카테고리 필터
- 수량 + 단위
- 메모
- 자주 사는 물건 등록 및 원터치 재추가
- 구매완료 이동 / 되돌리기
- 완료 항목 일괄 삭제
- 카테고리/단위 직접 추가, 이름 변경, 삭제
- JSON 백업 내보내기/불러오기
- 브라우저 로컬 저장
- PWA 설치 및 오프라인 사용 지원

가장 간단한 사용법
1. 폴더 전체를 GitHub Pages, Netlify, Cloudflare Pages 같은 무료 정적 호스팅에 올립니다.
2. 휴대폰 Chrome/Samsung Internet에서 해당 주소를 엽니다.
3. 브라우저 메뉴에서 '홈 화면에 추가' 또는 '앱 설치'를 선택합니다.

주의
- 데이터는 기본적으로 해당 브라우저/기기에 저장됩니다.
- 브라우저 데이터를 지우거나 기기를 바꾸기 전에는 설정 > 백업 내보내기를 사용하세요.
- index.html을 컴퓨터에서 직접 열어도 기본 기능은 동작하지만, 설치형 PWA/오프라인 캐시는 HTTPS 주소에서 사용하는 것이 좋습니다.
